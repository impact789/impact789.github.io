# Privacy policy

_Last updated: September 26, 2026_

**Who this applies to.** EA Gateway is a private tool used only by its owner, on the owner's own accounts. It has no other users.

**What it accesses.** With the owner's explicit permission, EA Gateway reads the owner's own Google data (such as Gmail messages, calendar events and Drive files) **read-only**. It cannot send, modify or delete anything.

**How data is used.** Data is used only to provide the owner with summaries, reminders and security alerts about the owner's own accounts. Sensitive information is filtered before use, and the tool keeps as little as possible, for as short a time as possible.

**Sharing.** Data is never sold, rented, shared for advertising, or used to train general-purpose AI models. It is not transferred to anyone except as needed to provide the owner's own service, or as required by law.

**Storage and security.** Data is processed on systems controlled by the owner, with encryption, least-privilege access and audit logging.

**Google API Services User Data Policy.** EA Gateway's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Revoking access.** Access can be removed at any time at [myaccount.google.com/connections](https://myaccount.google.com/connections).

**Contact.** Via the support email shown on the app's Google sign-in screen.
