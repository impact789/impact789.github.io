# EA Gateway

EA Gateway is a **private, single-user tool**. It lets its owner's personal assistant read the owner's **own** email, calendar and documents on a **read-only** basis, with privacy filtering applied before anything is used.

- It is not offered to the public and has no other users.
- It never sends, changes or deletes email, events or files.
- It never sells, shares or advertises with anyone's data.
